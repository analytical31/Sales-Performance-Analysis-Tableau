# Sales Performance Dashboard (Tableau)</br>
An interactive Tableau dashboard that analyzes sales, profit, and order trends across product categories, regions, customer segments, and shipping modes.</br>
## Overview</br>
This dashboard gives a quick view of business performance. It tracks key KPIs and lets users explore where revenue and profit come from, and which products and customer groups drive them.</br>
